## What You Need To Build

### Step 1: Create a product generation script

Create a file at `scripts/fill-supply-gaps.mjs` that:

1. Connects to the Supabase database (same pattern as `scripts/audit-listings.mjs` — use `pg` package, read `SUPABASE_DATABASE_URL` or `DATABASE_URL` from env)

2. For each vehicle + part combination below, creates a product listing with:
   - Realistic product name (e.g., "Toyota Camry 2012-2017 Front Brake Pads (Ceramic)")
   - Real OEM or aftermarket part number (search for the actual part number)
   - Realistic Ghana market price in GHS
   - Proper category ID (look up from the `categories` table)
   - Vehicle make, model, year range
   - Condition: mix of "new" and "used"
   - Description: 2-3 sentences about the part, fitment, and what it does
   - Quantity: 1-5

3. For each product, searches for a matching product image (use Bing Image Search or Google), uploads it to Cloudinary (same pattern as `scripts/audit-listings.mjs`), and stores the Cloudinary URL.

4. Assigns the product to a randomly selected approved vendor from the database (distribute products across vendors so no single vendor gets all the new parts).

5. Inserts the product into the `products` table.
